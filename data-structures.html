Data Structures: A Complete Beginner's Guide

Learn data structures with simple explanations, examples, algorithms and practical programming concepts.

1. Introduction to Data Structures

A data structure is a method of organizing and storing data so that it can be accessed and processed efficiently.

Choosing a suitable data structure can make a program easier to design and can improve the efficiency of operations such as searching, insertion, deletion and sorting.

Simple definition: A data structure organizes data in a way that makes operations on the data efficient and manageable.

Why Learn Data Structures?

  • Helps organize large amounts of data.
  • Improves program efficiency.
  • Makes searching and sorting easier.
  • Supports efficient memory usage.
  • Important for software development and technical interviews.

2. Classification of Data Structures

Data structures can be broadly classified into linear and non-linear data structures.

Type Examples
Linear Array, Linked List, Stack, Queue
Non-Linear Tree, Graph

Linear Data Structures

In a linear data structure, elements are arranged sequentially. Each element generally has a logical predecessor and successor, except at the ends.

Non-Linear Data Structures

In a non-linear data structure, elements are not arranged in one simple sequence. Trees and graphs are common examples.

3. Arrays

An array stores multiple values of the same data type under one variable name. Elements are accessed using an index. 

int[] numbers = {10, 20, 30, 40, 50};

System.out.println(numbers[0]);
System.out.println(numbers[3]);

Advantages

  • Simple to use.
  • Fast access using an index.
  • Useful when the number of elements is known.

Limitation

A normal Java array has a fixed size after creation.

3. Linked List

A linked list is a linear data structure where elements are stored in separate nodes. Each node contains data and a reference to the next node.

Structure of a Node

Data | Next → Data | Next → Data | NULL

Singly Linked List

In a singly linked list, every node points to the next node. The last node points to NULL. 

class Node {
    int data;
    Node next;

    Node(int data) {
        this.data = data;
        this.next = null;
    }
}

Advantages

  • Dynamic size
  • Easy insertion and deletion
  • Memory is allocated when required

Disadvantages

  • Extra memory is needed for links
  • Random access is not possible
  • Searching can be slower than arrays

4. Stack

A stack is a linear data structure that follows the LIFO (Last In, First Out) principle. 

        TOP
         ↓
       | 30 |
       | 20 |
       | 10 |
       -----

Basic Stack Operations

  • Push: Adds an element to the top.
  • Pop: Removes the top element.
  • Peek: Displays the top element.
  • isEmpty: Checks whether the stack is empty.

Example in Java

import java.util.ArrayDeque;

class StackExample {
    public static void main(String[] args) {

        ArrayDeque<Integer> stack = new ArrayDeque<>();

        stack.push(10);
        stack.push(20);
        stack.push(30);

        System.out.println("Top: " + stack.peek());

        stack.pop();

        System.out.println("After pop: " + stack.peek());
    }
}

Applications: Function calls, undo operations, expression evaluation, browser history and backtracking.

5. Queue

A queue is a linear data structure that follows the FIFO (First In, First Out) principle. 

FRONT                         REAR
  ↓                              ↓
| 10 | → | 20 | → | 30 |
  Remove                    Add

Basic Queue Operations

  • Enqueue: Adds an element to the rear.
  • Dequeue: Removes an element from the front.
  • Peek: Displays the front element.
  • isEmpty: Checks whether the queue is empty.

Example in Java

import java.util.ArrayDeque;

class QueueExample {
    public static void main(String[] args) {

        ArrayDeque<Integer> queue = new ArrayDeque<>();

        queue.add(10);
        queue.add(20);
        queue.add(30);

        System.out.println("Front: " + queue.peek());

        queue.remove();

        System.out.println("After remove: " + queue.peek());
    }
}

Applications: CPU scheduling, printer queues, customer service systems and task scheduling.

6. Trees

A tree is a non-linear data structure that represents data in a hierarchical form. It consists of nodes connected by edges.

Basic Tree Structure

              10
             /  \
            5    15
           / \     \
          2   7     20

Important Tree Terms

  • Root: The topmost node of a tree.
  • Parent: A node that has one or more children.
  • Child: A node connected below another node.
  • Leaf: A node that has no children.
  • Edge: Connection between two nodes.
  • Height: The longest path from a node to a leaf.

Binary Tree

A binary tree is a tree in which each node can have at most two children: a left child and a right child. 

class Node {
    int data;
    Node left;
    Node right;

    Node(int data) {
        this.data = data;
        left = null;
        right = null;
    }
}

Tree Traversals

  • Preorder: Root → Left → Right
  • Inorder: Left → Root → Right
  • Postorder: Left → Right → Root

Tree data structures are commonly used in searching, databases, file systems and hierarchical data representation.

7. Heap

A heap is a special type of binary tree that satisfies the heap property. It is commonly used in priority queues and heap sort.

Types of Heap

  • Max Heap: The parent node is greater than or equal to its children.
  • Min Heap: The parent node is smaller than or equal to its children.

Max Heap Example

              50
             /  \
           30    40
          / \    /
        10  20  35

In a max heap, the largest element is always present at the root.

Applications

  • Priority queues
  • Heap sort
  • Scheduling algorithms
  • Finding minimum or maximum elements

8. Hashing

Hashing is a technique used to store and retrieve data quickly. A hash function converts a key into an index of a hash table.

Basic Hash Function

h(key) = key % table_size

For example, if the table size is 10 and the key is 25: 

h(25) = 25 % 10
      = 5

Therefore, the key 25 can be stored at index 5.

Collision

A collision occurs when two different keys produce the same hash index.

Collision Resolution Techniques

  • Separate Chaining: Uses a linked list at each index.
  • Linear Probing: Searches the next available position.
  • Quadratic Probing: Uses quadratic increments to find a position.
  • Double Hashing: Uses a second hash function.

Advantages of Hashing

  • Fast searching
  • Fast insertion
  • Fast deletion
  • Efficient data retrieval

9. Graphs

A graph is a non-linear data structure consisting of vertices (nodes) and edges (connections).

Simple Graph

       A
      / \
     /   \
    B-----C
     \
      \
       D

Important Terms

  • Vertex: A node in a graph.
  • Edge: A connection between two vertices.
  • Degree: Number of edges connected to a vertex.
  • Path: A sequence of connected vertices.
  • Cycle: A path that starts and ends at the same vertex.

Types of Graphs

  • Directed Graph: Edges have a direction.
  • Undirected Graph: Edges have no direction.
  • Weighted Graph: Edges have associated weights.
  • Unweighted Graph: Edges do not have weights.

Graph Traversals

Two common graph traversal techniques are:

  • BFS: Breadth First Search uses a queue.
  • DFS: Depth First Search uses a stack or recursion.

Graphs are used in social networks, maps, computer networks, recommendation systems and route planning.

10. Searching

Searching is the process of finding a particular element in a collection of data.

Linear Search

Linear search checks each element one by one until the required element is found. 

int[] arr = {10, 20, 30, 40, 50};
int key = 30;

for (int i = 0; i < arr.length; i++) {
    if (arr[i] == key) {
        System.out.println("Element found at index " + i);
        break;
    }
}

Time Complexity: O(n)

Binary Search

Binary search works on a sorted array. It repeatedly divides the search range into two halves. 

int[] arr = {10, 20, 30, 40, 50};
int key = 40;

int low = 0;
int high = arr.length - 1;

while (low <= high) {
    int mid = (low + high) / 2;

    if (arr[mid] == key) {
        System.out.println("Element found");
        break;
    }
    else if (arr[mid] < key) {
        low = mid + 1;
    }
    else {
        high = mid - 1;
    }
}

Time Complexity: O(log n)

11. Sorting

Sorting is the process of arranging data in a particular order, usually ascending or descending order.

Common Sorting Algorithms

  • Bubble Sort
  • Selection Sort
  • Insertion Sort
  • Merge Sort
  • Quick Sort
  • Heap Sort

Bubble Sort

Bubble sort repeatedly compares adjacent elements and swaps them if they are in the wrong order. 

int[] arr = {5, 3, 8, 1, 2};

for (int i = 0; i < arr.length - 1; i++) {

    for (int j = 0; j < arr.length - i - 1; j++) {

        if (arr[j] > arr[j + 1]) {
            int temp = arr[j];
            arr[j] = arr[j + 1];
            arr[j + 1] = temp;
        }
    }
}

for (int x : arr) {
    System.out.print(x + " ");
}

Time Complexity: O(n²) in the average and worst cases.

Sorting Comparison

Algorithm Average Time Worst Time
Bubble Sort O(n²) O(n²)
Selection Sort O(n²) O(n²)
Insertion Sort O(n²) O(n²)
Merge Sort O(n log n) O(n log n)
Quick Sort O(n log n) O(n²)
Heap Sort O(n log n) O(n log n)

12. Time and Space Complexity

Complexity helps us measure how efficiently an algorithm uses time and memory.

Time Complexity

Time complexity describes how the running time of an algorithm increases as the input size increases.

Common Time Complexities

Complexity Name Example
O(1) Constant Accessing an array element
O(log n) Logarithmic Binary Search
O(n) Linear Linear Search
O(n log n) Linearithmic Merge Sort
O(n²) Quadratic Bubble Sort

Space Complexity

Space complexity describes the amount of extra memory required by an algorithm while it is running.

Efficient algorithms try to reduce both execution time and unnecessary memory usage.

Conclusion

Data structures are an important part of computer science and programming. Arrays, linked lists, stacks, queues, trees, heaps, hashing and graphs help programmers organize data efficiently.
