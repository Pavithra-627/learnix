1. Introduction to Digital Logic

Digital Logic is a branch of electronics and computer science that deals with digital signals and binary values. Digital systems mainly use two states: 0 and 1.

Digital logic is the foundation of computers, mobile phones, calculators, digital watches, communication systems and many other electronic devices.

Digital Signals

LOW  →  0
HIGH →  1

Why Digital Logic is Important

  • Forms the foundation of computers.
  • Helps in designing processors and memory systems.
  • Used in digital communication.
  • Used in control and automation systems.
  • Important for understanding computer hardware.
Remember: Digital systems represent information mainly using binary digits 0 and 1.

3. Number System Conversion

Decimal to Binary

To convert a decimal number into binary, repeatedly divide the number by 2 and record the remainders.

Example: Convert 13₁₀ to binary.

13 ÷ 2 = 6   remainder 1
 6 ÷ 2 = 3   remainder 0
 3 ÷ 2 = 1   remainder 1
 1 ÷ 2 = 0   remainder 1

Read remainders from bottom to top:

13₁₀ = 1101₂

Binary to Decimal

Multiply each binary digit by the corresponding power of 2 and add the results.

Example: Convert 1011₂ to decimal.

1011₂

= 1×2³ + 0×2² + 1×2¹ + 1×2⁰

= 8 + 0 + 2 + 1

= 11₁₀

Decimal to Octal

Repeatedly divide the decimal number by 8 and read the remainders from bottom to top.

Example: Convert 25₁₀ to octal.

25 ÷ 8 = 3   remainder 1
 3 ÷ 8 = 0   remainder 3

25₁₀ = 31₈

Decimal to Hexadecimal

Repeatedly divide the decimal number by 16 and convert remainders 10–15 into A–F.

Example: Convert 26₁₀ to hexadecimal.

26 ÷ 16 = 1   remainder 10

10 = A

Therefore:

26₁₀ = 1A₁₆

5. Boolean Algebra

Boolean algebra is a mathematical system used to analyze and simplify digital logic circuits.

Basic Boolean Operators

  • AND: A · B
  • OR: A + B
  • NOT: A'

Important Boolean Laws

Law Expression
Identity Law A + 0 = A    A · 1 = A
Null Law A + 1 = 1    A · 0 = 0
Idempotent Law A + A = A    A · A = A
Complement Law A + A' = 1    A · A' = 0
Double Complement (A')' = A
Commutative Law A + B = B + A
Associative Law (A+B)+C = A+(B+C)
Distributive Law A(B+C) = AB+AC

De Morgan's Laws

De Morgan's laws are very important for simplifying Boolean expressions. 

(A + B)' = A' · B'

(A · B)' = A' + B'
Exam Tip: Remember De Morgan's law by changing AND to OR, OR to AND, and complementing every variable.

7. Karnaugh Map (K-Map)

A Karnaugh Map, or K-Map, is a graphical method used to simplify Boolean expressions. It helps reduce the number of logic gates required in a digital circuit.

Purpose of K-Map

  • Simplifies Boolean expressions.
  • Reduces the number of logic gates.
  • Reduces circuit complexity.
  • Can reduce hardware cost and delay.

2-Variable K-Map

A \ B 0 1
0 m₀ m₁
1 m₂ m₃

Important K-Map Rules

  1. Place 1s in the cells corresponding to the given minterms.
  2. Make groups containing 1, 2, 4, 8 or more cells.
  3. Groups should contain the maximum possible number of cells.
  4. Groups can wrap around the edges of the K-Map.
  5. Write the simplified Boolean expression from the groups.

Example

Consider: 

F(A,B) = Σm(1,3)

The minterms 1 and 3 are grouped together. In both cells, the value of B remains 1. 

Therefore:

F = B
Exam Tip: Always make the largest possible groups in a K-Map. Groups must contain powers of 2 such as 1, 2, 4, 8, etc.

Flip-Flop

A flip-flop is a basic memory element that can store one bit of binary information.

The main types of flip-flops are:

  • SR Flip-Flop
  • JK Flip-Flop
  • D Flip-Flop
  • T Flip-Flop

SR Flip-Flop

SR stands for Set-Reset. It has two main inputs: S (Set) and R (Reset).

S R Operation
0 0 No Change
0 1 Reset
1 0 Set
1 1 Invalid condition*

*For the commonly taught NOR-gate SR latch, S=R=1 is the invalid condition. Behavior depends on the specific implementation.

JK Flip-Flop

JK flip-flop is an improved form of the SR flip-flop. It eliminates the invalid input condition found in the basic NOR SR latch.

J K Operation
0 0 No Change
0 1 Reset
1 0 Set
1 1 Toggle

D Flip-Flop

D flip-flop is also called a data or delay flip-flop. It has a single data input D. 

Q(next) = D

When the clock triggers the flip-flop, the value of D is transferred to Q.

T Flip-Flop

T flip-flop is called the toggle flip-flop. When T = 1, the output changes to its opposite state.

T Operation
0 No Change
1 Toggle

Registers

A register is a group of flip-flops used to store multiple bits of binary information.

For example, a 4-bit register can store four binary bits. 

Bit 3   Bit 2   Bit 1   Bit 0
 ↓       ↓       ↓       ↓
[ FF ]  [ FF ]  [ FF ]  [ FF ]

Types of Registers

  • Serial-In Serial-Out (SISO)
  • Serial-In Parallel-Out (SIPO)
  • Parallel-In Serial-Out (PISO)
  • Parallel-In Parallel-Out (PIPO)

Registers are used for temporary data storage and data transfer inside digital systems and processors.

Counters

A counter is a sequential circuit used to count clock pulses. Counters are generally constructed using flip-flops.

Binary Counter

A binary counter changes its state according to the incoming clock pulses. 

Clock pulses:

0 → 1 → 2 → 3 → 4 → 5 → ...

Binary:

000 → 001 → 010 → 011 → 100 → 101 → ...

Types of Counters

  • Asynchronous Counter: Flip-flops do not receive the clock simultaneously.
  • Synchronous Counter: All flip-flops receive the clock simultaneously.
  • Up Counter: Counts upward.
  • Down Counter: Counts downward.
  • Up/Down Counter: Can count in both directions.

10. Frequently Asked Questions

1. What is Digital Logic?

Digital Logic deals with digital signals represented mainly using binary values 0 and 1.

2. What is a logic gate?

A logic gate is a digital circuit that performs a logical operation on one or more inputs.

3. What is a K-Map?

A Karnaugh Map is a graphical technique used to simplify Boolean expressions.

4. What is a combinational circuit?

A combinational circuit produces an output based only on its present inputs.

5. What is a sequential circuit?

A sequential circuit produces an output based on present inputs and previous states.

6. What is a flip-flop?

A flip-flop is a basic memory element capable of storing one bit of information.

7. What are the types of flip-flops?

The common types are SR, JK, D and T flip-flops.

8. What is a register?

A register is a group of flip-flops used to store multiple bits of binary data.

9. What is a counter?

A counter is a sequential circuit that counts clock pulses.

10. Where is digital logic used?

Digital logic is used in computers, processors, memory, calculators, communication systems and digital control systems.

Conclusion

Digital Logic is the foundation of modern digital electronics. Number systems, logic gates and Boolean algebra help us understand how digital circuits operate.

K-Maps are useful for simplifying Boolean expressions, while combinational circuits perform operations based on current inputs. Sequential circuits use memory elements such as flip-flops, registers and counters.

Learning these concepts provides a strong foundation for computer architecture, electronics, embedded systems and hardware-related subjects.
