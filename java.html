Java Basics: A Complete Beginner's Guide

Learn Java programming step by step with simple explanations, examples, programs, tables and important exam topics.

1. Introduction to Java

Java is a high-level, object-oriented programming language developed by Sun Microsystems. It is widely used for web applications, mobile applications, desktop software, enterprise applications and many other software systems.

Java follows the principle "Write Once, Run Anywhere". Java programs are compiled into bytecode, which can run on any system that has a Java Virtual Machine (JVM).

How Java Works

Java Source Code → Compiler → Bytecode → JVM → Output

JDK, JRE and JVM

  • JDK: Java Development Kit used to develop Java programs.
  • JRE: Java Runtime Environment used to run Java programs.
  • JVM: Java Virtual Machine executes Java bytecode.

2. Features of Java

Java provides several important features:

  • Simple: Java has a clear and easy-to-understand syntax.
  • Object-Oriented: Programs are organized using classes and objects.
  • Platform Independent: Java bytecode can run on different platforms.
  • Secure: Java provides security features for application development.
  • Robust: Java provides exception handling and automatic memory management.
  • Portable: Java programs can be moved between different systems.
  • Multithreaded: Java supports execution of multiple tasks at the same time.
  • High Performance: The JVM uses Just-In-Time compilation to improve performance.
  • Distributed: Java supports network-based and distributed applications.
  • Dynamic: Java can load classes and resources when required.

3. Basic Java Program

A Java program is written inside a class. The program execution starts from the main() method. 

class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

Explanation

  • class: Defines a class.
  • main(): Starting point of program execution.
  • System.out.println(): Displays output on the screen.

4. Variables in Java

A variable is a named memory location used to store data. Every variable has a data type and a value. 

int age = 20;
double salary = 25000.50;
char grade = 'A';
String name = "Pavithra";

Types of Variables

  • Local Variable: Declared inside a method or block.
  • Instance Variable: Declared inside a class but outside methods.
  • Static Variable: Declared using the static keyword and shared by objects.

5. Data Types in Java

A data type specifies what type of value a variable can store. Java data types are divided into primitive and non-primitive types.

Primitive Data Types

Data Type Example Use
byte byte x = 10; Small integer values
short short x = 100; Integer values

long long n = 100000L; Large whole numbers
float float x = 10.5f; Decimal values
double double x = 24.89; Precise decimal values
char char grade = 'A'; Single character
boolean boolean pass = true; True or false values

Non-Primitive Data Types

Examples include String, Arrays, Classes and Interfaces. 

String name = "Pavithra";
int[] marks = {80, 85, 90};

6. Operators in Java

Operators are symbols used to perform operations on variables and values.

Types of Operators

7. Conditional Statements

Conditional statements are used to execute different blocks of code depending on a condition.

if Statement

int age = 20;

if (age >= 18) {
    System.out.println("Eligible to vote");
}

if-else Statement

int marks = 75;

if (marks >= 40) {
    System.out.println("Pass");
} else {
    System.out.println("Fail");
}

else-if Statement

int marks = 85;

if (marks >= 90) {
    System.out.println("A Grade");
} else if (marks >= 75) {
    System.out.println("B Grade");
} else if (marks >= 50) {
    System.out.println("C Grade");
} else {
    System.out.println("Fail");
}

switch Statement

int day = 2;

switch (day) {
    case 1:
        System.out.println("Monday");
        break;
    case 2:
        System.out.println("Tuesday");
        break;
    default:
        System.out.println("Invalid day");
}

8. Loops in Java

Loops are used to execute a block of code repeatedly.

for Loop

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

while Loop

int i = 1;

while (i <= 5) {
    System.out.println(i);
    i++;
}

do-while Loop

int i = 1;

do {
    System.out.println(i);
    i++;
} while (i <= 5);

Enhanced for Loop

int[] numbers = {10, 20, 30, 40};

for (int n : numbers) {
    System.out.println(n);
}
Remember: A for loop is commonly used when the number of repetitions is known, while a while loop is useful when the condition controls the repetition.

9. Arrays in Java

An array is a collection of elements of the same data type stored under a single variable name. Array indexing starts from 0.

One-Dimensional Array

int[] marks = {80, 85, 90, 75};

System.out.println(marks[0]);
System.out.println(marks[2]);

Using a for Loop

int[] numbers = {10, 20, 30, 40, 50};

for (int i = 0; i < numbers.length; i++) {
    System.out.println(numbers[i]);
}

Two-Dimensional Array

int[][] matrix = {
    {1, 2},
    {3, 4}
};

System.out.println(matrix[0][1]);
Important: Array size is fixed after the array is created.

10. Classes and Objects

A class is a blueprint for creating objects. An object is an instance of a class. 

class Student {
    int id;
    String name;

    void display() {
        System.out.println(id + " " + name);
    }

    public static void main(String[] args) {
        Student s1 = new Student();

        s1.id = 101;
        s1.name = "Arun";

        s1.display();
    }
}

Key Points

  • A class contains data members and methods.
  • An object is created using the new keyword.
  • Multiple objects can be created from one class.

11. Constructors in Java

A constructor is a special member of a class that is automatically called when an object is created.

Rules of Constructors

  • The constructor name must be the same as the class name.
  • A constructor does not have a return type.
  • It is called automatically when an object is created.
  • Constructors can be overloaded.

Example

class Student {
    int id;
    String name;

    Student(int id, String name) {
        this.id = id;
        this.name = name;
    }

    void display() {
        System.out.println(id + " " + name);
    }

    public static void main(String[] args) {
        Student s1 = new Student(101, "Arun");
        s1.display();
    }
}

Constructor Overloading

Constructor overloading means having more than one constructor in the same class with different parameter lists. 

class Student {
    int id;
    String name;

    Student() {
        id = 0;
        name = "Unknown";
    }

    Student(int id, String name) {
        this.id = id;
        this.name = name;
    }
}

12. this Keyword

The this keyword refers to the current object of a class. It is commonly used when instance variables and constructor parameters have the same name. 

class Student {
    int id;
    String name;

    Student(int id, String name) {
        this.id = id;
        this.name = name;
    }

    void display() {
        System.out.println(id + " " + name);
    }
}
Example: this.id refers to the instance variable, while id refers to the constructor parameter.

13. Inheritance

Inheritance is an OOP feature in which one class acquires the properties and methods of another class. It promotes code reusability.

Basic Syntax

class Parent {
    void display() {
        System.out.println("Parent class");
    }
}

class Child extends Parent {
    void show() {
        System.out.println("Child class");
    }
}

class Main {
    public static void main(String[] args) {
        Child obj = new Child();

        obj.display();
        obj.show();
    }
}

Types of Inheritance

  • Single Inheritance: One child class inherits from one parent class.
  • Multilevel Inheritance: A class inherits from another derived class.
  • Hierarchical Inheritance: Multiple child classes inherit from one parent class.
  • Multiple Inheritance: A class inherits from multiple sources. Java supports this through interfaces.

14. Method Overloading

Method overloading means having multiple methods with the same name but different parameter lists in the same class. 

class Calculator {

    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }

    double add(double a, double b) {
        return a + b;
    }

    public static void main(String[] args) {
        Calculator c = new Calculator();

        System.out.println(c.add(10, 20));
        System.out.println(c.add(10, 20, 30));
        System.out.println(c.add(10.5, 20.5));
    }
}
Remember: Method overloading is an example of compile-time polymorphism.

15. Method Overriding

Method overriding occurs when a child class provides its own implementation of a method already defined in the parent class. 

class Animal {
    void sound() {
        System.out.println("Animal makes a sound");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}

class Main {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.sound();
    }
}
Important: Method overriding is an example of runtime polymorphism.

16. Abstraction

Abstraction is the process of hiding implementation details and showing only the essential features to the user.

Abstract Class

abstract class Animal {

    abstract void sound();

    void eat() {
        System.out.println("Animal is eating");
    }
}

class Dog extends Animal {

    void sound() {
        System.out.println("Dog barks");
    }

    public static void main(String[] args) {
        Dog d = new Dog();

        d.sound();
        d.eat();
    }
}
Note: An abstract class can contain both abstract methods and normal methods.

17. Interfaces

An interface defines a contract that implementing classes must follow. Interfaces are commonly used to achieve abstraction and multiple inheritance of type in Java. 

interface Animal {
    void sound();
}

class Dog implements Animal {

    public void sound() {
        System.out.println("Dog barks");
    }

    public static void main(String[] args) {
        Dog d = new Dog();
        d.sound();
    }
}

Multiple Inheritance Using Interfaces

interface A {
    void showA();
}

interface B {
    void showB();
}

class C implements A, B {

    public void showA() {
        System.out.println("Interface A");
    }

    public void showB() {
        System.out.println("Interface B");
    }

    public static void main(String[] args) {
        C obj = new C();

        obj.showA();
        obj.showB();
    }
}

18. Exception Handling

Exception handling is used to handle runtime errors and prevent abnormal termination of a program.

try-catch

class Example {
    public static void main(String[] args) {

        try {
            int result = 10 / 0;
            System.out.println(result);
        }
        catch (ArithmeticException e) {
            System.out.println("Cannot divide by zero");
        }
    }
}

Multiple catch Blocks

try {
    int[] numbers = {10, 20};
    System.out.println(numbers[5]);
}
catch (ArithmeticException e) {
    System.out.println("Arithmetic error");
}
catch (ArrayIndexOutOfBoundsException e) {
    System.out.println("Array index error");
}
catch (Exception e) {
    System.out.println("Some other error");
}

finally Block

The finally block normally executes whether an exception occurs or not. It is commonly used for cleanup operations. 

try {
    System.out.println("Try block");
}
catch (Exception e) {
    System.out.println("Exception occurred");
}
finally {
    System.out.println("Finally block");
}

19. throw and throws

throw

The throw keyword is used to explicitly throw an exception. 

class Example {

    public static void main(String[] args) {

        int age = 15;

        if (age < 18) {
            throw new ArithmeticException("Not eligible to vote");
        }

        System.out.println("Eligible to vote");
    }
}

throws

The throws keyword declares exceptions that a method may throw. 

class Example {

    static void check() throws Exception {
        throw new Exception("An error occurred");
    }

    public static void main(String[] args) {

        try {
            check();
        }
        catch (Exception e) {
            System.out.println(e.getMessage());
        }
    }
}
Difference: throw is used to actually throw an exception, while throws declares possible exceptions in a method signature.

20. final Keyword

The final keyword is used to restrict changes in Java. It can be used with variables, methods and classes.

final Variable

final int MAX = 100;

System.out.println(MAX);

Once a final variable is assigned a value, that value cannot be changed.

final Method

class Parent {

    final void display() {
        System.out.println("Parent method");
    }
}

A final method cannot be overridden by a child class.

final Class

final class Vehicle {
    void show() {
        System.out.println("Vehicle");
    }
}

A final class cannot be inherited by another class.

21. Type Casting

Type casting is the process of converting a value from one data type to another.

Widening Type Casting

Widening converts a smaller data type into a larger data type. It is usually performed automatically. 

int a = 15;
double b = a;

System.out.println(b);

Here, int is automatically converted into double.

Narrowing Type Casting

Narrowing converts a larger data type into a smaller data type. Explicit casting is required. 

double d = 24.89;
int x = (int) d;

System.out.println(x);

Output: 

24
Remember: Narrowing may cause loss of decimal or other information.

22. Command-Line Arguments

Command-line arguments are values passed to a Java program when it is executed. They are stored in the String[] args parameter of the main method. 

class Demo {

    public static void main(String[] args) {

        System.out.println("Name: " + args[0]);
        System.out.println("Age: " + args[1]);
    }
}

Example execution:

java Demo Pavithra 20

In this example, Pavithra is stored in args[0] and 20 is stored in args[1].

23. Important Java Programs

Program 1: Check Even or Odd

class EvenOdd {
    public static void main(String[] args) {

        int n = 10;

        if (n % 2 == 0) {
            System.out.println("Even");
        } else {
            System.out.println("Odd");
        }
    }
}

Program 2: Find Largest of Two Numbers

class Largest {
    public static void main(String[] args) {

        int a = 25;
        int b = 40;

        if (a > b) {
            System.out.println("A is largest");
        } else {
            System.out.println("B is largest");
        }
    }
}

Program 3: Sum of Array Elements

class ArraySum {
    public static void main(String[] args) {

        int[] numbers = {10, 20, 30, 40};
        int sum = 0;

        for (int n : numbers) {
            sum = sum + n;
        }

        System.out.println("Sum = " + sum);
    }
}

26. Frequently Asked Questions

Is Java suitable for beginners?

Yes. Java has a structured syntax and is widely used for learning object-oriented programming.

Why is Java platform independent?

Java source code is compiled into bytecode, which can run on different platforms using a compatible JVM.

What is the difference between JDK, JRE and JVM?

JDK provides tools for developing Java applications. JRE provides the environment needed to run Java applications. JVM executes Java bytecode.

Can Java support multiple inheritance?

Java does not support multiple inheritance of classes, but multiple inheritance of type can be achieved using interfaces.

What is the difference between throw and throws?

throw is used to explicitly throw an exception, while throws is used to declare exceptions that a method may throw.
